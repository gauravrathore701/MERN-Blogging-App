# MERN Blogging App

`MySQL, Express, React and NodeJS`

## Project Brief:

- This project was created during a hack-a-thon conducted during my CDAC Course by Sunbeam Institute.
- The main purpose of this project is to showcase the technologies we learned up until now.
- This is not a fully scaled project in terms of functionality and UI designs. But this project does implement encryption techniques to make it secure and it also follows good coding practices.

## Technologies used are:

### MySQL

- MySQL was the primary choice of database due to it's simplicity and my familiarity with the query language.

### React

- React is used to build the front-end designs of the project.
- The **use of Hooks, React-Router-Dom, Navigate Hook, Toastify and some other modules can be seen**.
- We also used Bootstrap 3.0 to speed up the design process of the web app.

### NodeJS

- For Server side we used NodeJS as our primary scrypting language.

#### Packages used in the NodeJS are:

##### JWT

##### Crypto-JS

##### Express

##### CORS

##### MySQL-2
